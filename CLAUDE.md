# tendorethane-code.github.io

The owner's GitHub Pages user site: the root of `https://tendorethane-code.github.io/`. It holds
the landing page, `.well-known/assetlinks.json` (Android TWA verification for the owner's APKs)
and `.nojekyll`. Project sites such as `/jalur-maps/` come from their own repos.

The owner writes casual Indonesian; reply the same way. They want a sparring partner, and they
asked for this repo to catch what they forget.

**Whenever this repo is in a session:** read `README.md`, run every item of "Cek rutin" that can
be checked from here (curl the live URLs and the Digital Asset Links API, look through the repos
in the session), and tell the owner plainly what is off. Then ask them the items that can't be
checked from here. Keep README.md in Indonesian and up to date when apps, packages or keys change.

Never commit signing keys or passwords. Fingerprints are public and belong in the README table and
`assetlinks.json`.
